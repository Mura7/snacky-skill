# Faith pool: Quran verses and hadith

Ready-made list for the **faith** interest. Each entry has an exact reference, a Diyanet link and a short meaning written in our own words. The own-words meaning is **not** the Diyanet translation; it exists so the card never depends on the network. How to use it is in [interests.md](interests.md#faith-pool).

- Verses: 115 entries, ids `A001`…; source link `https://kuran.diyanet.gov.tr/tefsir/sure/{surah}?kaynak=1`.
- Hadith: 118 entries, ids `H001`…, all main hadiths of topics in *Hadislerle İslâm* (Diyanet); the link opens that topic page.
- Pool version: 1 (2026-10-21).
